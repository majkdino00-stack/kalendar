# Афиша мероприятий — GitHub Pages + Supabase

## Состав
- `index.html`, `style.css`, `app.js` — сайт.
- `config.js` — параметры подключения к Supabase.
- `supabase.sql` — создание таблиц и политик доступа.

## Подключение общей базы
1. Создайте проект на https://supabase.com/.
2. Откройте SQL Editor и выполните содержимое `supabase.sql`.
3. В Project Settings → API скопируйте Project URL и публичный anon key.
4. Вставьте их в `config.js`. Не используйте `service_role` key.
5. В Supabase включите Realtime для таблицы `events` (Database → Publications).

## Публикация на GitHub Pages
1. Создайте GitHub-репозиторий.
2. Загрузите все файлы из этой папки в корень репозитория.
3. Откройте Settings → Pages.
4. Выберите Deploy from a branch, ветку `main`, папку `/ (root)` и нажмите Save.
5. Дождитесь публикации и откройте адрес, который покажет GitHub Pages.

## Проверка
Добавьте тестовое событие, затем откройте сайт на другом устройстве. При подключённом Supabase событие должно быть видно там тоже. Проверьте редактирование и удаление; записи удаления находятся в таблице `deletion_logs`.

## Важно о доступе
Регистрация в согласованном варианте не предусмотрена. SQL-политики разрешают любому посетителю читать, добавлять, менять и удалять события. Никнейм не подтверждает личность. Это удобно для открытого редактирования, но небезопасно для публичного сайта: любой посетитель может испортить данные. Перед публичным запуском нужно отдельно согласовать защиту/права доступа. Не публикуйте секретные ключи.

## Ограничения первой сборки
- В исходных уточнениях не определены часы начала/окончания события. Поэтому пока задаются даты, а дневной просмотр показывает события без выдуманного времени. Для почасовой шкалы нужно согласовать поля времени.
- Синхронизация обнаруживает изменения и предлагает обновить страницу; автоматическое разрешение одновременных конфликтующих правок пока не реализовано.
- Без Supabase сайт работает в демо-режиме с локальными данными одного браузера; это не общая база.
- Интерфейс использует CDN для Supabase JS и Google Fonts, поэтому для этих ресурсов нужен интернет.
